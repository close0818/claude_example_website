使用 go-sqlmock 驗證 handler 的 SQL 呼叫、參數、HTTP 回應和交易期望；不連線、不寫入實際 MySQL 資料。

Race detector 未完成

go test -race ./... 的測試程序以 Windows 結束碼 0xc0000139 中止，沒有產生 race 結果。這不是測到競態，也不能列為通過。

目前未涵蓋db.Open 的資料庫/Schema 建立、真實 MySQL 權限與重啟行為、借閱併發競態、圖書更新/單筆查詢、會員與借閱列表、SQL 錯誤及 rows.Err() 分支。其他 package 目前沒有測試。

品質改善建議

依風險排序
P1
確保借閱資料一致性

改用條件式原子更新或 row lock，檢查受影響列數，並用併發測試保證同一本書不會重複借出。

P1
以隔離 MySQL 驗證首次初始化

測試自動建庫、逐表建置、權限不足時 fail fast，以及重複啟動不破壞資料。

P1
建立 API 安全邊界

加入認證與角色授權、限制 CORS 來源，資料庫改用最小權限帳號並透過 secret 注入憑證。

P2
擴大 handler 測試和錯誤路徑

補齊讀取/更新、無效 ID、SQL 故障、掃描失敗與 rows.Err() 測試，統一錯誤狀態碼。

P2
建立自動化品質門檻

在 CI 執行 gofmt 檢查、go vet、go test、可用平台上的 race test，並逐步提高 coverage 門檻。
